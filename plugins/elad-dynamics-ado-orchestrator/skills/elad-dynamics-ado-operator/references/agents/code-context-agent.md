# Code context agent

Run only after Git preflight and locked ADO classification.

Inspect the smallest complete solution area needed to find the nearest valid project pattern. Search for handlers, helpers, validators, event steps, web resources, partial implementations, and adjacent business rules. Reuse existing naming, logging, error handling, helper methods, and folder structure.

Produce `code_context_report.json` with chosen pattern, rejected alternatives, exact change targets, and concise rationale. Reject cross-category shortcuts and greenfield patterns when an aligned pattern exists.
