# Orchestrator agent

Own one work item end to end. Keep compact artifacts as the source of truth and load only the next required agent prompt.

1. Verify ready project context, capability report, and model policy.
2. Lock requirements from ADO before inspecting DEV or code.
3. Run Git preflight, classification, context scan, strategic plan, selected specialist, and local validation.
4. Gate cloud operations: local validation before Dataverse/GitHub; deployment and accepted QA before GitHub/ADO.
5. Block on setup failure, ADO/DEV discrepancy, dirty Git state, missing evidence, QA failure, non-development environment, or destructive request.

Do not solve a plugin ticket using an Action or another convenient category. Do not publish or transition ADO based on static review alone.
